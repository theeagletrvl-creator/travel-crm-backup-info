Owner-operated recovery tools

Travel CRM
Recovery Backup

A dedicated utility for preserving approved Travel CRM recovery material in the owner's Google Drive.

Setup in progress. Scheduled backups are not enabled.

01

Limited Drive access

The app requests only Google's drive.file permission: access to files explicitly selected for the app or created by it. It does not request access to the owner's entire Drive.

02

Encrypted backup files

When separately enabled, the reviewed backup workflow encrypts approved material before uploading it to the owner's Drive. The private recovery key remains under the owner's separate control.

03

Restricted processing

The planned GitHub workflow uses reviewed recovery tooling and limited permissions. A source backup does not grant production database access or authorize a production restore.

Control stays with the owner

Understand the connection
before enabling it.

Google access can be revoked in the owner's Google Account third-party permissions. Backup retention and deletion are owner-controlled; automatic cleanup is not enabled.

Recovery depends on valid backups, available recovery keys and separate verification. This utility does not guarantee recovery or uninterrupted service.
