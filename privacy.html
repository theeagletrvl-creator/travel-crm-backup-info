Travel CRM Recovery Backup

Privacy notice

This notice covers Eagle Travel's owner-operated backup utility only. It does not replace the live CRM's privacy policy.

Last updated: October 26, 2026

Current status: Connection setup is in progress. Scheduled backup processing is not enabled. The practices below describe this utility when the connection and individual workflow are approved and enabled.

Operator and purpose

Eagle Travel operates this utility to preserve approved project and recovery material for its own business. Contact: theeagletrvl@gmail.com.

Google Drive access

The utility requests only https://www.googleapis.com/auth/drive.file. This permits access to specific Drive files explicitly selected for the app or created by it, rather than general access to the owner's Drive. The intended destination is a private, owner-controlled backup folder.

Within that permitted set, the utility uses file identifiers, folder association, sizes, checksums and encrypted file contents to upload and verify backups and avoid duplicate copies. It does not request Gmail access, Google passwords, or whole-Drive access.

Processing and credential handling

When enabled, a reviewed GitHub Actions workflow prepares approved recovery material, encrypts it before upload and verifies the resulting ciphertext. Dedicated connection credentials are intended to be stored as encrypted GitHub Actions secrets and used only by the restricted upload step. The private backup decryption key is not supplied to that workflow.

Backup contents may contain business or project information approved by the owner. They are not published on this website or in public repositories. Nonsecret verification receipts may record file identifiers, sizes, hashes, dates and success or failure status. They must exclude credentials and plaintext backup contents.

Use and service providers

Accessed data is used for the approved backup and recovery purpose. Eagle Travel does not sell this Google user data or use it for advertising or model training. Google Drive stores the backup files; GitHub provides the reviewed workflow processing and this information website. No additional recipient is configured by this setup.

These static information pages contain no forms, analytics scripts or tracking cookies added by Eagle Travel. The hosting provider may process ordinary request metadata under its own policies.

Retention, deletion and revocation

The owner controls backup retention and deletion in Drive. There is no automatic retention or deletion schedule enabled. Retained copies can remain until the owner removes them.

The owner can revoke this app's access through Google Account third-party permissions and remove its dedicated GitHub Actions secrets. Disconnecting the app does not itself delete existing backups. Deletion of copies from Drive, GitHub or other owner-controlled storage must be handled in the respective service.

Limits and changes

Encryption and limited permissions reduce exposure; they do not eliminate every risk or guarantee successful recovery. Recovery requires usable backups, the correct private recovery key and appropriate verification. Production database exports, restores and additional integrations require separate approval.

This notice will be reviewed if the utility's access, data handling or enabled processing changes. Questions or deletion requests may be sent to the business contact above.
